# MCP 서버

MCP(Model Context Protocol)는 외부 도구나 서비스를 표준화된 방식으로 Claude 같은 에이전트에 연결하는 프로토콜이다. Claude Code 자체에 내장되어 있지 않은 기능이라도, MCP 서버로 연결해두면 그 서버가 제공하는 도구를 마치 원래 있던 도구처럼 호출할 수 있다.

## 어떤 식으로 쓰이는가

예를 들어 IDE와 연동되는 MCP 서버를 붙이면 IDE 안의 파일 읽기, 코드 검색, 실행 설정 실행, 데이터베이스 조회, 디버거 제어 같은 기능을 Claude Code에서 도구로 바로 쓸 수 있게 된다. 사내 이슈 트래커나 사내 데이터베이스에 붙는 MCP 서버를 연결하면 그 시스템의 데이터를 조회하거나 수정하는 작업도 대화 안에서 처리할 수 있다.

## 도구가 많아질 때

연결된 MCP 서버가 늘어나면 한 번에 쓸 수 있는 도구 수도 같이 늘어난다. 도구 목록이 너무 많아지면 그 목록 자체가 컨텍스트를 차지하기 때문에, 자주 쓰지 않는 도구는 이름만 먼저 알려주고 실제로 필요할 때 검색해서 스키마를 불러오는 방식으로 관리하기도 한다. 이렇게 하면 도구가 수십 개 연결돼 있어도 매 순간 컨텍스트에는 지금 필요한 도구의 정보만 올라온다.
