# 권한 모드

Claude Code는 파일을 고치거나 셸 명령을 실행하는 등 실제로 시스템에 영향을 주는 도구를 쓸 수 있다. 그 도구 호출을 얼마나 자동으로 허용할지를 정하는 설정이 권한 모드다.

## 기본 동작

기본 모드에서는 파일 읽기처럼 되돌리기 쉬운 동작은 바로 실행하지만, 파일을 새로 쓰거나 셸 명령을 실행하는 것처럼 영향이 있는 동작은 실행 전에 사용자에게 승인을 받는다. 한 번 승인한 종류의 명령은 세션 설정에 따라 이후 자동으로 허용되기도 한다.

## 계획 모드

계획 모드에서는 파일을 실제로 바꾸지 않고 조사와 설계만 진행한다. 복잡한 작업을 시작하기 전에 어떤 순서로 무엇을 바꿀지 먼저 정리해서 보여주고, 사람이 그 계획을 확인한 뒤에야 실제 실행 단계로 넘어간다. 방향을 잘못 잡은 채로 파일을 여러 개 건드리고 나서 되돌리는 것보다, 계획 단계에서 방향을 맞추는 편이 비용이 적게 든다.

## 자동 승인과 위험한 모드

승인 절차를 아예 건너뛰고 모든 도구 호출을 자동으로 허용하는 모드도 있다. 반복적인 작업을 빠르게 처리할 때는 편하지만, 삭제나 강제 push처럼 되돌리기 어려운 명령까지 확인 없이 실행될 수 있다는 뜻이기도 하다.

> [!CAUTION]
> 모든 도구 호출을 자동 승인하는 모드는 신뢰할 수 있는 반복 작업에만 쓴다. 승인 없이 실행되면 곤란한 저장소(운영 배포, 공유 브랜치)에서는 쓰지 않는 게 안전하다.

## 세부 조정

프로젝트나 사용자 설정 파일에 특정 명령을 항상 허용하거나 항상 차단하는 목록을 등록해둘 수도 있다. 예를 들어 읽기 전용 git 명령은 항상 허용하고, 원격 저장소에 강제로 push하는 명령은 항상 차단하는 식으로 세밀하게 조정한다. 이렇게 하면 매번 모드를 바꾸지 않아도 자주 쓰는 안전한 명령에 대한 승인 절차만 줄일 수 있다.
