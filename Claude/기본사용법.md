# Claude Code 기본 사용법

## Claude Code란

Claude Code는 터미널에서 실행하는 에이전틱 코딩 도구다. 채팅창에 코드를 복사해서 붙여넣고 답을 받아 다시 옮기는 방식이 아니라, 프로젝트 디렉토리 안에서 직접 파일을 읽고 고치고 명령을 실행하면서 작업을 끝까지 수행한다.

설치는 npm으로 하고(`npm install -g @anthropic-ai/claude-code`), 작업할 프로젝트 디렉토리에서 `claude` 명령을 실행하면 그 디렉토리를 프로젝트로 인식한 대화형 세션이 시작된다.

## 동작 방식

기본 흐름은 다음과 같다.

1. 사용자가 자연어로 요청한다.
2. Claude가 요청을 처리하는 데 필요한 도구(파일 읽기, 파일 수정, 셸 명령 실행 등)를 스스로 판단해서 호출한다.
3. 도구 실행 결과를 보고 다음에 뭘 할지 다시 판단한다.
4. 이 과정을 요청이 끝날 때까지 반복하고, 마지막에 사람이 이해할 수 있는 말로 결과를 정리해서 알려준다.

이 반복 구조를 에이전트 루프라고 부른다. 사람이 매 단계마다 다음 명령을 입력해주는 게 아니라, 하나의 요청 안에서 필요한 조사와 실행을 Claude가 스스로 이어서 처리한다는 점이 일반적인 챗봇 사용과 다르다.

## 세션과 컨텍스트

한 번 실행한 `claude` 세션은 대화가 끝날 때까지 이전에 나눈 내용과 실행 결과를 기억한다. 대화가 길어지면 오래된 내용은 자동으로 요약되어 컨텍스트 공간을 관리하기 때문에, 세션이 길어진다고 이전 작업 맥락이 갑자기 끊기지는 않는다.

## 알아두면 좋은 기능

기본적인 대화형 작업 외에 실무에서 자주 쓰게 되는 기능들이다. 각각의 자세한 동작 방식은 별도 문서로 정리했다.

- 도구를 실행할 때마다 승인을 받을지, 자동으로 진행할지는 [권한 모드](./권한모드.md)로 정한다.
- 규모가 크거나 반복적인 하위 작업은 [서브에이전트](./서브에이전트.md)에 위임해서 메인 대화의 맥락을 깨끗하게 유지할 수 있다.
- 파일을 수정한 뒤 자동으로 포맷을 맞추는 것처럼, 특정 시점마다 명령을 자동 실행하고 싶다면 [훅](./훅.md)을 쓴다.
- 자주 반복하는 작업 절차는 [스킬](./스킬.md)로 만들어두면 슬래시 커맨드 하나로 불러 쓸 수 있다.
- 데이터베이스나 사내 시스템처럼 외부 도구를 Claude Code에 붙이려면 [MCP 서버](./MCP서버.md)를 연결한다.
- 프로젝트마다 지켜야 할 규칙이나 반복해서 알려주기 귀찮은 교훈은 [프로젝트 메모리](./프로젝트메모리.md)에 남겨두면 다음 세션에서도 유지된다.
- 하나의 프로젝트를 세션 여러 개로 나눠서 작업하는 방법은 [여러 세션으로 작업하기](./여러세션으로작업하기.md)에 따로 정리했다.
